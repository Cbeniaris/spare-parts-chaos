## [PythonSDK](https://bl-sdk.github.io/) mods for Borderlands 2
Shout out to LaryIsland for the original mod. I play with this all the time on "insane" mode.  I wanted that little bit of extra chaos though.  This fork adds one extra mode titled "Chaos" for removing the requirement of crafting the same gun type into another.  Want to craft a Harold onto a Hyperion SMG? Go for it. 


## ORIGINAL: [Spare Parts](SpareParts) [[PythonSDK](https://bl-sdk.github.io/mods/SpareParts/)] [[NexusMods](https://www.nexusmods.com/borderlands2/mods/404)]

- Allows you to salvage parts from items and attach them to other items.
- The item you salvage parts from will be destroyed in the process.
- Requires [UserFeedback](https://bl-sdk.github.io/mods/UserFeedback/) and [Python Part Notifier](https://bl-sdk.github.io/mods/PythonPartNotifier/)
- ADDITIONAL CHAOS MODE:  allows crafting of different weapon types together.  All safe guards removed.
